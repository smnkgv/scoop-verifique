# Scoop bucket for verifique

```powershell
scoop bucket add verifique https://github.com/smnkgv/scoop-verifique
scoop install verifique
```

verifique runs project commands with the `sh` that comes with Git for Windows, so install that too if
you haven't: `scoop install git` or `winget install Git.Git`. See
[verifique](https://github.com/smnkgv/verifique).
